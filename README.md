# spreacte

## Demo

A simple demo app is available in the `demo/` directory.

### Run demo

1. From `d:\REPO\spreacte` install dependencies:
   - `yarn install`
2. From `d:\REPO\spreacte\demo` install dependencies:
   - `yarn install`
3. Start the demo:
   - `cd demo && yarn start`

### What the demo shows

- `GlobalContextProvider` wrapping consumer content
- `Box` component layout and responsive sizing
- `useModal` hook to open and close a modal
- `utils.numberWithCommas` and `utils.isDev` usage
